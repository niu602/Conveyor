# Conveyor Courier

A parcel desk for Marrow Point, built as an open agentic website with the
[agentify-website](https://github.com/cognizant-ai-labs/agentic-web) skill. It prices
same-day runs between local businesses, records accepted jobs on its own intake, and lets
another site's assistant hand a delivery to it.

This is a developer demo. Jobs are recorded on a test desk: no parcel is collected and no
payment is taken.

## Run it

From the repository root, with the official repository checked out at `D:\OpenAgenticWeb`
(the commands below assume that path; change `SKILL_DIR` if yours differs):

```powershell
$SKILL_DIR = "D:\OpenAgenticWeb\skills\agentify-website"

# 1. The desk's intake, on this machine, with an in-memory store.
node D:\Conveyor\courier-site\worker\local-server.mjs --port 8086

# 2. This site, opened as localhost so a partner on 127.0.0.1 keeps its own key cookie.
node "$SKILL_DIR\scripts\serve_site.mjs" D:\Conveyor\courier-site --port 8085 --open-as localhost
```

Open <http://localhost:8085/>. The page works without the assistant: get a quote, refresh
the desk, look up a job and cancel one.

To talk to the assistant, expand **⚙ AI model settings**, paste a key for the provider you
choose, and select **Save and start**. Afterwards select **Delete setup** under
**Advanced settings (optional)** and close the tab: the tab keeps using the key until it
is closed. On `localhost` and `127.0.0.1` the runtime also copies saved setups, keys
included, into a cookie any local site can read, so use a key with a low spending limit.

The assistant sends your messages, and the page data it reads, to the LLM provider you
pick. Nothing else leaves the page except the calls to this desk's own intake.

### Demo job

`J-DEMO-1` is on the desk from the first start, made through the desk's own operations by
`demo-job.js`. Its details are made up and belong to no one. The sample queries about a
job number use it.

## The network

One front agent, `courier_desk_assistant`, on `alibaba/qwen3.8-flash` by default.

| Action | Effect | What it does |
| --- | --- | --- |
| `get_dispatch_state` | read | Zones, parcel sizes, fees, hours, today, and the page's facts with links |
| `request_quote` | read | Prices a run and holds the quote for 15 minutes; books nothing |
| `lookup_job` | read | One job's status, fee and events; no personal details |
| `cancel_job` | irreversible | Cancels a job that has not been picked up; this site's dialog asks first |

`confirm_dispatch` is registered only by the bridge, so it is never a tool on this page.

The desk cannot take payment, book for another day, collect at a named time, deliver
outside Marrow Point, carry more than 12 items, insure a parcel, or change a job's zone,
parcel or fee once accepted. The agent says so instead of improvising.

## The desk's intake

`worker/index.js` runs unchanged on Cloudflare Workers with D1 and on Node with an
in-memory store. Both use the rules in `courier-desk.js`.

| Endpoint | Purpose |
| --- | --- |
| `POST /api/quote` | Price a run and hold the quote |
| `POST /api/dispatch/check` | The read-only check a dispatch runs first |
| `POST /api/dispatch` | Record a job, once per idempotency key |
| `GET /api/jobs`, `GET /api/jobs/:id` | Read jobs, without personal details |
| `POST /api/jobs/:id/cancel` | Cancel before pickup |
| `POST /api/jobs/:id/advance` | Move a job to its next status |

Every dispatch carries an `idempotency_key`. A replay of a key returns the first job,
unchanged, even when the second call carries different details. A call whose outcome is
unknown is settled by reading the job, never by dispatching again.

CORS is limited to `http://localhost:8085` and `http://127.0.0.1:8084`. Business endpoints
never send `*`; a stranger gets 403 and no CORS header.

To deploy, create a D1 database, put its id in `worker/wrangler.toml`, apply
`worker/schema.sql`, and set `DeskClient.LOCAL_BASE` in `desk-client.js` to the deployed
Worker's origin. Add that origin to `ALLOWED_ORIGINS` in `worker/index.js` if it differs.

## Calling this site

The network URL is the folder that holds `agent-manifest.json`, then the network name:
`http://localhost:8085/courier_dispatch` on this machine.

A calling site adds:

- `allowed_peers`: `"http://localhost:8085"`
- the calling agent's `tools`: `"http://localhost:8085/courier_dispatch"`
- `link_labels`: `"http://localhost:8085/courier_dispatch": "Conveyor Courier"`

The caller's visitor sees a consent card naming this site before anything is fetched.
**Always allow** skips the card for that host until the page is reloaded. The card shows
only the first 140 characters of the request; the partner gets all of it.

What a caller gets, and only from the origins `bridge/bridge-actions.js` lists:

| Shared action | Effect | Where it runs |
| --- | --- | --- |
| `get_dispatch_state` | read | A hidden frame on this origin |
| `request_quote` | read | A hidden frame on this origin |
| `lookup_job` | read | A hidden frame on this origin |
| `confirm_dispatch` | irreversible | **This site's own window** |

`cancel_job` is not shared: a caller's visitor cancels on this site's page.

`confirm_dispatch` takes only the quote, the fee the caller quoted and the parcel. It
never takes a name, phone number or address. The window shows the fee and the parcel, and
the visitor types their own details there; they go straight to this desk's intake. The
calling chat gets back the job number, status, fee and trip minutes — never those details.
On **Keep it with them** it gets `ok: false` and nothing is recorded.

The caller's network runs in its visitor's browser on that visitor's key, and a call costs
more than the card's token estimate.

## Limits

- Static hosting plus a Worker for the intake. The browser runtime is the skill's patched
  copy; do not replace it.
- `read` and `write` actions run with no dialog. Only `irreversible` asks first, and a
  partner's write asks in this site's own window.
- Every agent sees every `website_*` tool this page registers.
- The network file, including its instructions, is public.
- The LLM provider must allow CORS.
- The local intake keeps jobs in memory: restarting it clears them.
