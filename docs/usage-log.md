# Usage log — 模型通道与额度

四栏制：**日期与场景 / 通道与档位 / 实测事实（证据出处）/ 对额度与排期的影响**。
（栏位口径可按需要调整；本文件只记可复核的事实，不记推测的账单数字。）

**计量口径先说清**：反代日志记的是**请求字节数**，不是 token 数，更不是金额。
下面的字节数只能证明"发了多少次、发了多大"，**不能据此折算扣费**。真实消耗以智谱控制台账单为准。
日志按设计不记 key 值，只记 `key: server` / `key: visitor`。
